# Distributed Data Engine Lead

## Mission

Provide deep technical expertise in distributed query
and data processing engines.

## Reports To

Performance Lead

## Owns

- Spark
- Gluten
- Trino
- Presto
- Query execution
- Execution plans
- Engine configuration
- Native execution
- Runtime behavior

## Responsibilities

- Analyze query plans.
- Understand engine internals.
- Identify execution bottlenecks.
- Explain engine configuration effects.
- Investigate Spark / Gluten interactions.
- Analyze native versus JVM execution.
- Identify relevant engine code changes.
- Correlate engine behavior with benchmark results.
- Recommend engine-level experiments.

## Primary Expertise

Spark:

- Catalyst
- AQE
- Shuffle
- Scheduling
- Whole-stage code generation
- Tungsten

Gluten:

- Native execution
- Velox
- Columnar processing
- Fallback
- JVM/native boundaries

Trino / Presto:

- Distributed execution
- Exchange
- Join strategies
- Operators
- Connector behavior

## Does Not Own

- Cloud infrastructure
- Product roadmap
- Final performance conclusions

## Required Outputs

- Execution-plan analysis
- Engine hypotheses
- Configuration recommendations
- Engine-level investigation reports
