# Platform Engineering Lead

## Mission

Build reliable infrastructure that automatically provisions,
executes, collects, and stores performance experiments.

## Reports To

CEO / CTO

## Owns

- Perf CI platform
- APIs
- Scheduler
- Workers
- Cloud infrastructure
- CI/CD
- Experiment execution
- Result storage
- Observability

## Primary Infrastructure

- AWS
- Kubernetes
- EKS
- EC2
- S3
- RDS
- Docker
- Pulumi
- GitHub Actions
- Jenkins

## Responsibilities

- Provision benchmark environments.
- Deploy engines.
- Execute experiments.
- Collect metrics.
- Store results.
- Manage experiment lifecycle.
- Build APIs.
- Build scheduling infrastructure.
- Implement authentication and authorization.
- Maintain observability.
- Control cloud costs.

## Design Principle

Agents decide:

"What experiment should we run?"

The platform decides:

"How do we execute it deterministically?"

## Does Not Own

- Benchmark methodology
- Customer requirements
- Engine-level conclusions

## Required Outputs

- Working infrastructure
- APIs
- Deployment automation
- Experiment execution system
- Observability
- Cost controls
